# 💳 Credit Card Dashboard

A Power BI dashboard that provides comprehensive insights into credit card customers, transactions, revenue, and spending behavior. The dashboard helps analyze customer demographics, financial performance, and business trends through interactive visualizations.

---

## 📌 Features

- 📊 Interactive Power BI Dashboard
- 💰 Revenue and Transaction Analysis
- 👥 Customer Demographics Analysis
- 💳 Credit Card Usage Insights
- 📈 Weekly & Monthly Performance Tracking
- 🌍 Geographic Analysis
- 📉 Revenue by Card Category
- 📋 Customer Segmentation
- 🎯 KPI Monitoring

---

## 🛠️ Tools & Technologies

- Power BI
- Microsoft Excel / CSV
- Data Cleaning
- Data Visualization
- Power Query
- DAX (Data Analysis Expressions)
